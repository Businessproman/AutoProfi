## Mercedes на текущем первом экране

- Источник: по сведениям пользователя, актуальное изображение Mercedes создано пользователем с помощью генерации изображений ChatGPT.
- Оригинал: `assets/images/mercedes-new.png`, 6688 × 3764 пикселя, RGBA, 9 806 387 байт. Сохранён без изменений; SHA-256: `6eb259e40cb8c8db4c6683eb361919361163d45e38c167482b2c29b1ea8a630b`.
- Производные созданы исключительно из этого оригинала установленным Chrome: уменьшение Canvas 2D с `imageSmoothingQuality='high'`, WebP с максимальным качеством (`quality=1`). Проверка контейнера подтвердила **WebP lossless (VP8L)** во всех пяти файлах: кодирование без потерь после уменьшения разрешения. Альфа-канал каждой версии точно совпадает с результатом уменьшения до соответствующего размера.

- Сайт выбирает WebP через `<picture>`, `srcset` и `sizes` для обычных и Retina-экранов; исходный PNG служит запасным вариантом для браузеров без WebP. Прозрачные поля сохранены. CSS удерживает точные исходные пропорции, компенсируя округление высоты производных до целых пикселей.
- Масштаб, положение и свечение соответствуют утверждённому варианту B; контактные тени под шинами и кузовом взяты из C и выполнены CSS-градиентами. Сам автомобиль не ретушировался, фон не добавлялся.
- Старый `assets/images/mercedes-cutout.png` сайтом больше не используется. Он оставлен на диске без изменений.
- `design-reference.png` использован только как визуальный образец. Скриншот не вставляется вместо HTML-элементов сайта.
